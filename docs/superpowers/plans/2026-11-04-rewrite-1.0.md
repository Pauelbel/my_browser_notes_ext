# Заметки 1.0 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Переписать расширение «Заметки» с нуля: новое хранилище IndexedDB, дерево в стиле референса, одна верхняя полоса иконок, компактная заметка, бэкап на диск в настройках.

**Architecture:** Чистые модули без DOM (`tree.js`, `backup.js`) покрыты `node --test`. `db.js` — тонкая обёртка над IndexedDB. `editor-source.js` — обёртка Tiptap без знания о внешнем DOM, собирается в `vendor/editor.js`. `app.js` связывает всё с разметкой `index.html`.

**Tech Stack:** Chrome MV3, ванильный JS (ES-модули), Tiptap 3.31.3 + esbuild 0.28.2, `node:test` (Node 22).

**Spec:** `docs/superpowers/specs/2026-11-04-rewrite-design.md`

## Global Constraints

- Всё в папке `app/`; команды ниже выполняются из `app/`.
- Без сети в рантайме: никаких CDN, внешних шрифтов, удалённого кода.
- Разрешения manifest: только `sidePanel`. `minimum_chrome_version`: `"128"`. `version`: `"1.0.0"`.
- IndexedDB: база `notes`, версия 1, хранилища `notes`, `folders`, `kv`. Старая база `quiet-notes` удаляется при старте.
- `localStorage`: префикс `notes:`; старые ключи с префиксом `quiet-` удаляются при старте.
- Заметка: `{id, title, body, tags: string[], folderId: string|null, created: number, updated: number}`. Папка: `{id, name, parentId: string|null}`.
- Интерфейс на русском. Вне диалогов — только иконки, у каждой `aria-label` и `data-tip`.
- Сортировка `localeCompare(…, 'ru')`.
- Автосохранение через 500 мс; немедленно при `visibilitychange→hidden`, `pagehide`, смене заметки.
- Масштаб 70–120 %, шаг 5, раздельно для `?view=panel` и вкладки.
- Узкий режим: ширина < 560px.

## Review Focus

- Быстрый ввод, затем сразу закрытие панели — последнее изменение должно быть в базе (сохранение на `pagehide`/`visibilitychange`, без потери из-за debounce). → ручная проверка в Task 7.
- Одновременно открыты панель и вкладка, правка в одной — другая показывает новое дерево и не затирает чужую правку своей устаревшей копией, если у неё нет несохранённых изменений. → ручная проверка в Task 7.
- Названия с `/ \ : * ? " < > |`, пустые, `CON`, одинаковые в одной папке, папки с одинаковыми именами — бэкап создаёт валидные уникальные файлы. → тесты в Task 2.
- Перетаскивание папки в саму себя или потомка — запрещено, данные не портятся. → тест в Task 1.
- Поиск по тексту с регистром/ё и пустой запрос — совпадения показываются, папки с совпадениями раскрыты, счётчики корректны. → тесты в Task 1.

  - `parseTags(text) -> string[]` — разделители пробел/запятая, срезать ведущий `#`, без пустых и дублей.

### Task 2: `backup.js` — выгрузка на диск

**Files:**
- Create: `backup.js`, `tests/backup.test.js`

**Interfaces:**
- Consumes: `folderPath` из `tree.js`.
- Produces (`backup.js`):
  - `safeName(value: string) -> string` — заменить `<>:"/\|?*` и управляющие символы на `-`, срезать хвостовые точки/пробелы, обрезать до 70 символов; пустое или зарезервированное Windows-имя (`con|prn|aux|nul|com1-9|lpt1-9`) → `'Заметка'`.

    ```
    ---\ntitle: <JSON.stringify(title)>\ntags: <JSON.stringify(tags)>\ncreated: <ISO>\nupdated: <ISO>\n---\n<body>
    ```

  - `backupName(date: Date) -> string` — `Заметки-YYYY-MM-DD_HH-MM-SS` по локальному времени.

**Files:**

**Interfaces:**
- Produces (`db.js`), все функции асинхронные:

  - `kvGet(key) -> any`, `kvSet(key, value) -> void` (ключ `'backupDir'` — `FileSystemDirectoryHandle`).
  - После каждой записи — `channel.postMessage({type:'changed', id})` в `new BroadcastChannel('notes')`; экспорт `onExternalChange(callback: ({id}) => void)`.
