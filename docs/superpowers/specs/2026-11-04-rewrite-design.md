# Заметки 1.0 — полная переписка расширения

Дата: 2026-11-04. Статус: на согласовании.

## Зачем

Текущая версия (0.4.x) обросла синхронизацией с папкой, корзиной, экраном тегов, очередью операций и множеством кнопок. Интерфейс тяжёлый, код запутан. Цель — компактное расширение для личных заметок в боковой панели Chrome: дерево слева, заметка справа, все действия — иконками в одной верхней полосе. Пишем с нуля, без оглядки на старый код и старые данные.

## Цели

- Сайдбар в стиле первого референса (`wiki_data`): моноширинный шрифт, поиск сверху, дерево `◆ Папка · N` / `├─ ○ Заметка`, активная заметка `●`.
- Всё управление — одна верхняя полоса иконок с подсказкой при наведении.
- Отображение заметки максимально компактное: название, одна строка «путь к папке · теги · статус», дальше текст.
- Тёмная тема по второму референсу (тёмно-серый фон, оранжевый акцент), светлая — по первому (светлый фон, синий акцент).
- Чистый, небольшой, понятный код.

## Не цели (удаляется осознанно)

- Синхронизация с папкой на диске (постоянная, двусторонняя).
- Импорт/восстановление заметок с диска.
- Корзина. Удаление — сразу и навсегда, после подтверждения.
- Отдельный экран «Теги» и фильтр по тегу (теги ищутся обычным поиском).
- Старые данные: не мигрируются. Новая версия при старте удаляет старую базу IndexedDB `quiet-notes` и старые ключи `localStorage` с префиксом `quiet-`.

## Анти-цели (провал, даже если работает)

- Шапка заметки занимает больше двух строк над текстом.
- Кнопки с текстом в интерфейсе вне диалогов.
- Потеря введённого текста при закрытии панели или при одновременно открытых панели и вкладке.

## Подходы

1. **Переписать только интерфейс, хранилище оставить** — меньше риска, тесты хранилища живут, но остаётся мёртвый код синхронизации и старая модель данных.
2. **Полностью с нуля, включая хранилище** — чистый код и простая модель данных; цена — старые данные теряются (принято).

**Выбран вариант 2** (решение пользователя): «переписываем полностью без слёз и жалости, делаем чисто». Старые заметки удаляются, миграции нет.

## Что решено с пользователем

- Остаются: панель форматирования, настройки, переключение темы, резервное копирование на диск (внутри настроек).
- Бэкап — только выгрузка в одну сторону: из расширения в выбранную папку как `.md`.
- В настройках также остаются: масштаб интерфейса, положение сайдбара (слева/справа), «Открыть во вкладке», ссылка на настройки положения панели Chrome.
- Путь к папке в шапке заметки — только информационный текст, не кликабельный, не меняет папку.
- Форматирование живёт в той же верхней полосе, что и управление.

### Верхняя полоса

Одна строка, высота ~32px, иконки 16–18px (SVG, инлайн, единый stroke-стиль; не эмодзи). У каждой кнопки `aria-label` и своя CSS-подсказка (`data-tip`), появляется при наведении/фокусе без задержки браузерного `title`. Группы разделены тонкой вертикальной чертой.

- Слева: свернуть/развернуть сайдбар, новая заметка, новая папка, удалить текущую заметку.
- Центр: жирный, курсив, заголовок (H2), маркированный список, нумерованный список, список задач, цитата, код, таблица (выбор размера сеткой), картинка, убрать форматирование, отменить, повторить. Активное состояние кнопки подсвечивается.
- Справа: тема (светлая ↔ тёмная), настройки.
- Если полоса не помещается (узкая панель ~360px): группа форматирования прокручивается горизонтально без видимого скроллбара, левая и правая группы остаются на месте.
- Кнопки форматирования и «удалить» неактивны, когда заметка не открыта.

### Сайдбар

- Моноширинный шрифт (системный стек: `ui-monospace, "JetBrains Mono", "Cascadia Mono", Consolas, monospace`), 13px.
- Сверху поле «найти заметку…». Поиск без учёта регистра по названию, тексту и тегам; при непустом запросе показываются только совпадения, их папки раскрыты.
- Папки: `◆ Имя · N`, где N — число заметок в папке включая вложенные. Клик сворачивает/разворачивает. Свёрнутость запоминается.
- Заметки: `○ Название` (обрезается многоточием), текущая — `●` и акцентный цвет. Отступы и линии дерева `├─ └─ │` рисуются CSS-бордерами, не символами.
- Сортировка: папки и заметки по алфавиту (`localeCompare('ru')`), как в референсе.
- Заметки без папки идут в корне после папок.
- При наведении на папку справа появляется `⋮`: «Новая заметка здесь», «Новая подпапка», «Переименовать», «Удалить». На заметке `⋮` не нужен.
- Перетаскивание: заметку — в папку или в корень; папку — в другую папку или в корень (нельзя в саму себя/потомка).
- Ширина сайдбара — ~240px, перетаскиваемый разделитель между сайдбаром и заметкой, ширина запоминается.
- На узком экране (<560px) сайдбар по умолчанию свёрнут и при открытии перекрывает заметку; выбор заметки его закрывает.

### Заметка

- Строка 1: название — `input` без рамки, крупный жирный шрифт; плейсхолдер «Без названия».
- Строка 2 (мелко, приглушённый цвет): `Папка › Подпапка` (или «без папки») · теги-чипы `#тег` (× при наведении удаляет) · `＋` (раскрывает инлайн-поле с подсказками существующих тегов; Enter/пробел/запятая добавляют) · статус сохранения `✓ 15:48` / `…` / `!`.
- Дальше сразу редактор. Отступы минимальные.
- Нет открытой заметки (пустая база) — тихая подсказка по центру: «Нет заметок. Создайте первую — ＋ сверху».

## Данные

IndexedDB, база `notes`, версия 1. Хранилища:

- `notes`: `{id, title, body, tags: string[], folderId: string|null, created, updated}`; `id` — `crypto.randomUUID()`; `body` — Markdown.
- `folders`: `{id, name, parentId: string|null}`.
- `kv`: служебные значения, которые нельзя хранить в `localStorage` (дескриптор папки для бэкапа).

Мелкие настройки интерфейса (тема, сторона сайдбара, ширина сайдбара, свёрнутость, раскрытые папки, последняя открытая заметка, масштаб) — в `localStorage` с префиксом `notes:`. Масштаб раздельный для панели и вкладки, как сейчас.

Новая заметка создаётся в «текущей папке»: папке открытой заметки, либо в папке, у которой выбран пункт «Новая заметка здесь». Удаление папки удаляет все вложенные папки и заметки (диалог называет количество).

Автосохранение: через 500 мс после последнего изменения и немедленно при `visibilitychange → hidden` / `pagehide` / переключении заметки.

Панель и вкладка могут быть открыты одновременно: после каждой записи отправляется сообщение в `BroadcastChannel('notes')`, другая сторона перечитывает дерево; если у неё открыта та же заметка и в ней нет несохранённых изменений — перечитывает и её. Последняя запись выигрывает.

## Резервное копирование

В настройках: «Выбрать папку» (`showDirectoryPicker`, дескриптор сохраняется в `kv`) и «Сохранить копию». Каждая копия создаёт новую подпапку `Заметки-YYYY-MM-DD_HH-MM-SS` внутри выбранной; существующие файлы никогда не перезаписываются. Внутри — дерево папок как в расширении, каждая заметка — `<безопасное имя>.md` (повторы получают суффикс ` (2)`), формат:

```
---
title: "Название"
tags: ["qa", "kpi"]
created: 2026-11-04T12:00:00.000Z
updated: 2026-11-04T12:30:00.000Z
---
<markdown>
```

Под кнопкой — время последней копии и результат («Сохранено 42 заметки в Заметки-…») или текст ошибки. Если разрешение на папку утеряно — запрашивается при нажатии.

## Настройки (диалог)

Компактный модальный диалог: Резервная копия · Масштаб (ползунок 70–120%, шаг 5, сброс) · Сайдбар слева/справа · Открыть во вкладке ↗ · Положение панели Chrome ↗ (открывает `chrome://settings/appearance`).

## Темы

Токены цвета в `:root`; светлая и тёмная. По умолчанию — системная, кнопка переключает явно и запоминает.
- Светлая: фон `#fff`, сайдбар `#fafafa`, рамки `#e5e5e5`, текст `#1f2328`, приглушённый `#6e7781`, акцент `#2563eb`.
- Тёмная: фон `#2b2d31`, сайдбар `#232428`, рамки `#3a3c42`, текст `#e3e3e6`, приглушённый `#8b8d94`, акцент `#e0703a`.

## Технические рамки

- Chrome MV3, `side_panel` + вкладка (`index.html`), `background.js` только открывает панель по клику на иконку. Разрешения: `sidePanel`.
- Без сети: ни CDN, ни шрифтов извне.
- Редактор — Tiptap (StarterKit, Markdown, TaskList/TaskItem, Image с base64 и изменением размера, Table), собирается `esbuild` в `vendor/editor.js` из `editor-source.js`. Обёртка пишется заново: модуль экспортирует `createEditor(element, {onChange})` с методами `getMarkdown()`, `setMarkdown()`, `run(command)`, `isActive(command)`, `insertImage(dataUrl)`, `insertTable(rows, cols)`, `focus()`, `setEditable()` — и ничего не знает о DOM вне своего элемента. Тулбар строит `app.js`.
- Картинки: вставка из буфера и через кнопку, хранятся как data URL в Markdown.
- Структура файлов:
  - `manifest.json`, `background.js`, `index.html`, `style.css`
  - `app.js` — состояние и связывание UI
  - `db.js` — IndexedDB (notes/folders/kv), удаление старой базы
  - `tree.js` — чистые функции: построение дерева, счётчики, поиск, проверка допустимости переноса
  - `backup.js` — выгрузка на диск, сериализация заметки, безопасные имена файлов
  - `icons.js` — SVG-иконки строками
  - `zoom.js` — масштаб до первой отрисовки
  - `editor-source.js` → `vendor/editor.js`
- Удаляются: `cached-vault.js`, `storage.js`, `manual-archive.js`, `tags.js`, `serve.mjs`, `VERIFICATION.md`, `scripts/`, `tests/browser.*`, `tests/responsive.html`, неиспользуемые `icons/*.svg`, старые тесты.
- Тесты: `node --test` для чистых модулей (`tree.js`, `backup.js` — сериализация, имена, уникализация; выгрузка — на фейковом дескрипторе папки в памяти). Ручная проверка UI в панели 360px и во вкладке.
- README обновляется под новую версию; `manifest.version` → `1.0.0`.

## Решения автора дизайна (не обсуждались, можно поправить)

- Tiptap остаётся движком редактора — писать WYSIWYG с нуля нецелесообразно.
- В тулбар добавлены нумерованный список и блок кода (раньше их не было).
- Подсказки — свои CSS-тултипы, а не `title` (тот появляется с задержкой ~1 с).
- Изменяемая ширина сайдбара, автоскрытие сайдбара на узком экране.
- Синхронизация панели и вкладки через `BroadcastChannel`, «последняя запись выигрывает».
- Бэкап каждый раз создаёт новую подпапку с датой.
- Сортировка по алфавиту; тема по умолчанию — системная.

## Оставлено исполнителю

Точный рисунок SVG-иконок, отступы и мелкая типографика в пределах описанного; формулировки подсказок; поведение клавиатуры в дереве (минимум — Tab/Enter работают).
